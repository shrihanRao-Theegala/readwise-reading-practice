# ReadWise — Reading Comprehension Practice

## Run on your computer
1. Extract the ZIP.
2. Open `index.html` in Google Chrome, Microsoft Edge, or another modern browser.
3. Choose Easy, Medium, Hard, Extreme, or Impossible, then start a test.

## Features
- Five difficulty modes with progressively more demanding inference and evidence questions
- Larger passage, question, and answer text
- Instant scoring, grades, answer review, and explanations
- Progress history saved locally in this browser using localStorage
- Responsive layout and animations

## Important data note
This is a static website. Test history is saved only in the current browser on this device; it is not a cloud database and does not sync between users or devices.

## Publish free
You can host this static site with GitHub Pages. A real shared database/login system would require a backend or a service such as Supabase, with appropriate security rules.
